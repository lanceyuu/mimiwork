Notion connects through browser sign-in, and connected MCP tools become available in your existing chats.

- **Notion browser sign-in**: connect or reconnect your Notion account through its authorization page. MimiWork recognizes an existing Notion MCP connection and uses it without asking for a separate access token.
- **Tools stay current in chats**: added, removed, or reconnected MCP servers refresh before the next turn, including retries and resumed work. Connection status is included in the assistant’s context.
- **Large tool collections work together**: MimiWork discovers the tools it needs when connected services exceed the model’s tool limit. The full available catalog remains discoverable, with existing permissions preserved.
- **Clear connection status**: connector settings show connection progress, errors, and retry controls.
- **Personal appearance and notifications**: adjust text size, font, background tint, notifications, and sounds in Settings.
