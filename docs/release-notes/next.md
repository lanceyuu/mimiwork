New conversations and new automations now start at Accept edits. Mimi edits files in your folders without asking, while commands, sending messages and anything else that leaves your computer still ask. Conversations and automations you already have keep the permission level they had.

- **Linked files are checked** — if Mimi's reply links a file it never saved, Mimi is asked to save it or say plainly that it didn't, before it finishes. This stops file cards that open to "moved or deleted" for a file that was never written.
- **Sign-in** — the QualiTaTi sign-in card stays available even when MimiWork's background service is briefly unreachable, instead of showing "Loading…" with no way to sign in.
