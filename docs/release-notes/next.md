Claude Code and Codex now connect like any other tool. Open Connectors > Coding agents to see whether each one is installed and where, which account it is signed in with, and the model and effort Mimi's hand-offs will use. You can sign in with one click, or run the command shown in a terminal, and the Test button makes one small real call to check that everything works. If you ask Mimi for an agent that is not ready, Mimi tells you plainly and points you to that page.

- **Safer deletes**: deleting a conversation no longer removes a folder you chose to work in, and a forked conversation keeps the folder it shares with the original.
- **Honest automation results**: a scheduled run that hits a model error or runs out of steps is now recorded as failed, with the reason, and sends no "done" notice.
- **Clearer approvals**: a denied request now says "Denied" instead of "Approved: deny", and approving a plan lets file edits go ahead while commands and messages still ask.
- **Files page**: Word, Excel, PDF and image files open in their own app instead of showing unreadable characters.
- **Problems say so**: places that used to fail silently, such as saving a model choice or attaching the starting folder during setup, now explain what went wrong. Pop-up alerts are replaced by a short note next to what you did.
- **Steadier long tasks**: Mimi notices sooner when a tool keeps failing, recovers from malformed tool requests without stopping the conversation, and long command output no longer builds up in memory.
