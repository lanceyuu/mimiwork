Mimi can now hand software work to Cursor and Gemini CLI, you can set each coding agent's model from the chat, and opencode no longer stops on a retired free model.

- **Cursor and Gemini CLI join Claude Code, Codex and opencode** under Connectors ▸ Coding agents. Cursor runs on your own Cursor account and lists that account's models. Gemini CLI runs on your own Gemini API key: run `gemini` once in a terminal, type `/auth` and choose Use Gemini API Key. Google no longer lets Gemini CLI run on a personal Google sign-in, and Mimi says so plainly if you try. Antigravity has no command line Mimi could hand work to, so Gemini CLI is the Google option.
- **Set each agent's model from the chat**: while Mimi coordinates coding agents, the side panel lists each connected agent with its model and effort. You can change a model before approving a hand-off, and a change applies from that agent's next round.
- **opencode no longer fails on a retired free model**: opencode's own list could still offer a free model its service had retired, so hand-offs on the latest free model stopped at once. Mimi now switches to the replacement the service names and carries on. The model you choose was always the one used.
- **Reopening a hand-off works from any terminal**: the command under Recent hand-offs now names the agent by its full path, so it runs even when the agent is not on your terminal's PATH.
- **Long PDFs dropped into a chat are no longer refused**: a PDF over your page or size limit is saved into the chat's folder and read from there, instead of being sent whole with every message.
- **Automations keep their time when the clocks change**: a daily task set for 7:10 PM stayed tied to summer time, so after the clocks went back it would have run at 6:10 PM. It now follows your time zone on macOS and Linux.
