Mimi can use a key of yours for your own scripts, and can look at a picture in your folder.

- **Keys for your own scripts**: Settings, Models has a new card. Save a key under the name your script expects, such as `OPENROUTER_API_KEY`, and the commands Mimi runs can use it from the next message on. Mimi is told the name, never the key, and a key that a script prints is hidden before Mimi sees it. Any script Mimi runs can read these keys, so save only keys meant for scripts.
- **A key you paste is yours to use**: if you paste a key into the chat and ask Mimi to use it, Mimi now does, and says once that the key is saved in that conversation. Before, Mimi refused and sent you to the Terminal, where a key never reaches MimiWork.
- **Pictures in a folder**: Mimi can now open a picture file in your folder and look at it. Before, only pictures pasted into the chat were seen, so "open these images" got an answer that the model could not read pictures. Mimi looks at up to four pictures in one step and is told to come back for the rest.
