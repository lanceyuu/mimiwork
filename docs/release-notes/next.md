A safety fix for approvals, and an easier way to tell us when something goes wrong.

- **Safer approvals**: a command Mimi runs on your computer can no longer reach the app's own controls. Before this fix, a command you had approved could have read the key the app uses internally and then acted without asking you again. We found this in our own review of the code. Update to stay protected.
- **Report this problem everywhere**: the Report this problem button used to appear only on chat and connection errors. It is now beside every error the app shows, including the References tab, file previews, connectors, coding agents, Settings and scheduled runs. Nothing is sent until you confirm, and you see what will be sent first.
