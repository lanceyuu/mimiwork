opencode joins Claude Code and Codex as a third coding agent. opencode is the open-source coding agent from opencode.ai: it works with many model providers, and it comes with free models, so it is ready the moment it is installed, with no account needed. Connectors > Coding agents now shows all three.

- **Set up like the others**: the page shows where opencode is installed, which providers you have added to it, and a Test button that makes one small real call. The Model list comes from opencode's own list, newest first, with opencode's choice at the top; the Effort list follows the model you pick.
- **Says plainly how it works**: during a hand-off opencode does not stop to ask before it edits files or runs commands in its folder. Anything your own opencode settings mark to ask about, like reading outside that folder, is refused. Mimi still asks you before every hand-off, and in a git project opencode works on its own branch, so nothing reaches yours until you approve a merge.
- **Works in a team**: Mimi can mix opencode with Claude Code and Codex on one job, send it feedback in the same opencode session, and list its hand-offs with a command that reopens each one in opencode itself.
