Slides built around photographs, Mimi who knows MimiWork, keys you only give once, and Mail that shows what you sent.

- **Slides, image first**: a new deck is built around photographs that are free of copyright, found in a stock photo library and in Wikimedia Commons, with a credits slide at the end. Two new layouts: a photograph that fills the slide with a short line over it, and a few lines beside a half-page photograph. Text is set larger on slides that hold little, titles wrap instead of shrinking, and numbers are drawn large. Mimi no longer rewrites the same deck over and over, and a deck in Chinese is no longer rebuilt because the preview could not draw it.
- **Mimi knows MimiWork**: Mimi has a guide to MimiWork itself and looks things up in it, so she names the real places in the app, sets up coding agents correctly in Agents, and says when she is not sure. App messages that pointed to a "Manage" menu, which does not exist, now name the right place. When the free allowance runs out, the message now says to switch to Mimi Wolf.
- **Keys you only give once**: paste a key in a chat and Mimi can keep it for your scripts in every later conversation, after asking you. In Settings, Models, "Keys for your own scripts" now takes any key, and you can paste the lines of a .env file to save them all at once.
- **Agents**: a link to an agent system in a chat now opens it in Agents. A saved system runs from any chat, and a coding agent's name put where a model goes is caught before the run.
- **Mail**: a Sent tab lists what you sent, and Ask Mimi answers questions about the open conversation or your whole mailbox in a new chat.
- **Fixes**: web searches that came back empty now try other search engines; websites open on networks that use only IPv6; an email attachment is found even when one character of its name was copied wrongly.
