# Teal Mimi

User-provided Qualitati/Mimi puppy artwork adapted into an animated pet with the built-in image generation tool and hatch-pet deterministic assembly. Imported with the owner’s permission on 2026-09-15.

`spritesheet.webp`: 1536 × 2288, 8 columns × 11 rows of 192 × 208 cells. All images are transparent. `preview.png` is the first resting frame.

Rows: 0 idle (6), 1 move right (8), 2 move left (8), 3 static resting compatibility fallback (4), 4 jump (5), 5 failed (8), 6 waiting for input (6), 7 working (6), 8 review (6), 9–10 clockwise look directions (16).

The owner rejected the waving motion; its artwork is removed. No MimiWork animation uses row 3. Rendering maps working to row 7, completion to row 4, attention to row 6, and idle to row 0. The existing Classic Mimi remains the default.
