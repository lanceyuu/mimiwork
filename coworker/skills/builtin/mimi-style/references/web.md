# Web & HTML email

- Layout: max-width 1080px marketing / 720px docs; paper background; cards white with
  1px line border and 12px radius; hover lifts to the soft shadow, nothing more.
- Hero: ink headline (48-56px), one teal word or phrase via `<span>`, muted subhead,
  ONE teal primary button (white text, 10px radius) + one quiet secondary (line border).
- Feature grids: `tiles/` icons at 48-56px, heading 17px semibold, body 14px muted.
  Same container family across the grid.
- Bands: alternate paper and tint sections; a single teal band for the final CTA with
  white text and `dark/` icons.
- Buttons: teal background → teal-dark on hover; never outline-only for the primary.
- Email: same tokens, tables-for-layout, system font fallback is fine; one tile icon
  per section max, mascot only in the footer sign-off.
