# Documents & PDF (tutorials, one-pagers, reports)

A4 or Letter, 2cm margins, paper background on covers/bands only (body pages print white).

- Cover: teal band (full-width, ~35% height) with white product name + title; mascot
  `puppy-sitting` or `puppy-standing` white-knocked or in a white circle; date + author
  small, white, bottom of band.
- Headings: H1 22pt semibold ink with a 3pt teal rule below; H2 15pt teal-dark; H3 12pt
  ink semibold. Body 10.5–11pt, 1.35 line height.
- Callouts: tint background card, 1px line border, `outline/` icon left, max 4 lines.
- Step lists (tutorials): teal circle numbers (or `circles/` icons when a motif fits);
  screenshots get a 1px line border, 8px radius, and a caption in muted 9pt.
- Tables: header row tint-deep, ink semibold; hairline rows; no vertical rules.
- Footer: page number right, product name left, both muted 8pt.
- The 13-page MimiWork tutorial PDF is the reference implementation of this guide.
