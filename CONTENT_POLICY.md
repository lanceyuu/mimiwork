# MimiWork content policy

MimiWork is for work, learning and research. Pornography, sexually explicit
entertainment, sexual deepfakes and requests to undress people are prohibited.
This applies to generating, finding, displaying and distributing that content,
including through connected tools and custom model providers.

Factual, non-graphic health, scientific, educational, journalistic and research
discussion remains allowed. Discussing or preventing pornography is different
from producing it.

The application supplies this rule to every model request, refuses identifiable
explicit requests before calling a model, and checks tool arguments even when
the user has already granted tool access. DuckDuckGo and Brave searches request
their strongest supported SafeSearch setting.

These are layered restrictions, not a guarantee that every custom model, web
page, attachment or generated image has been classified. The local request guard
recognizes explicit wording; it is not a semantic or image moderation model.
MimiWork is not a child-directed product and does not claim universal child-safe
results. Please report unexpected explicit output to contact@qualitati.com,
without attaching the explicit material itself.
